<Callout kind="note">
Two habits worth more than any single answer. Say what you are trading away — an answer with a named cost beats one presented as free. And when there is a better question underneath the one asked, ask it: whether all ten thousand rows need to be in the browser, whether that state should be shared at all, whether the fix is a memo or a move.
</Callout>
